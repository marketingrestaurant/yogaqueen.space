# yogaqueen.space

Личный сайт и лендинги йога-тичера Анны Корчагиной (бренд **Yoga Queen**). Лендинги продвигают курсы, ретриты и йога-кайт-сафари: продажа "в лоб" на холодную аудиторию через платную рекламу (Google Ads, Meta, TikTok) с формой захвата лида.

## О бизнесе

- **Формат**: авторские онлайн- и офлайн-курсы по йоге, индивидуальные занятия, йога-ретриты, йога-кайт-сафари.
- **Юрлицо**: ANDIKO, s.r.o. (Прага, Чехия) — фигурирует в дисклеймерах лендингов.
- **Аудитория**: русскоязычная, преимущественно холодный трафик из платной рекламы.
- **Доставка контента**: часть офферов (например, бесплатный курс) выдаётся через Telegram-бота после заполнения формы.

## Технологии

Сайт полностью работает на **Tilda.cc**. Этот репозиторий не деплоится напрямую — здесь **генерируется самодостаточный HTML/CSS/JS** для кастомного HTML-блока Tilda (**Zero Block / T123**), который затем вручную копируется в редактор Tilda.

- Без фреймворков и сборки — чистый HTML/CSS/JS, один файл на лендинг.
- Mobile-first вёрстка — обязательное требование.
- Каждый лендинг самодостаточен (инлайновые стили/скрипты), т.к. вставляется как единый блок кода в Tilda.

## Структура лендингов

Референс — [yogaqueen.space/free](https://yogaqueen.space/free). Порядок секций одинаков для всех офферов, меняется только наполнение (текст, оффер, медиа):

1. Hero + форма захвата лида (обязательно на первом экране, без скролла)
2. Ключевые преимущества оффера
3. Программа / что входит
4. Как это работает (шаги)
5. Об инструкторе (Анна Корчагина, сертификат International Yoga Alliance)
6. FAQ
7. Юридический дисклеймер (RU/EN, ANDIKO s.r.o.)
8. Футер (соцсети, подписка, копирайт, ссылки на политику/условия)

## Файлы

Каждый лендинг — отдельный файл `landings/<слаг-оффера>.html`, например:

- `landings/free.html`
- `landings/retreat-bali.html`
- `landings/kite-safari.html`

## Обязательные требования к каждому лендингу

- Форма захвата лида на первом экране (above the fold)
- Mobile-first
- SEO: title/description/Open Graph/canonical/schema.org
- GEO в двух смыслах:
  - Generative Engine Optimization — структурированные данные и чёткие прямые ответы для AI-поисковиков (ChatGPT, Perplexity, AI Overviews)
  - Гео-таргетинг/локализация — под страну/регион/язык аудитории оффера
- Аналитика и пиксели, вшитые в каждый лендинг:
  - Google Analytics 4 + Google Ads (конверсии)
  - Meta (Facebook/Instagram) Pixel

## Деплой

Ручной: HTML-файл лендинга целиком копируется в HTML-блок (T123/Zero Block) на странице в редакторе Tilda.
